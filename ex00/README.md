# Project 04 - Personal Portfolio (Capstone)

## Author
Rania Alassouli - Full-Stack Web Developer

## Overview
An authentic, responsive personal developer portfolio website created from scratch using semantic HTML5, modern CSS3, dynamic JavaScript DOM manipulation, and Git.

## File Structure
- `index.html`: Semantic layout including Header, About Me, Skills, Projects, Hobbies, Contact, and Footer.
- `style.css`: Responsive design built using Flexbox, CSS Grid, Media Queries, and CSS variables for theme switching.
- `script.js`: Handles interactive theme toggling and DOM mutations.
- `assets/`: Contains image assets.

## Key Features
- Zero external frameworks or libraries.
- Mobile-responsive layout.
- Interactive Dark/Light theme toggle.
